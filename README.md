# MentePC Compressor Health Analyzer

Upload MentePC CSV data for instant Green/Amber/Red health diagnostics.

## Deploy to Streamlit Cloud

1. Upload this folder to GitHub
2. Go to share.streamlit.io
3. Create new app
4. Select repository
5. Main file: app.py
6. Deploy!

## Usage

1. Open app URL
2. Upload MentePC CSV or try Demo Mode
3. Click Analyze
4. View results
